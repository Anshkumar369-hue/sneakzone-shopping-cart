# Sneakzone Shopping Cart – Sprint 1

This repository contains my Sprint 1 shopping cart contribution for the Sneakzone e-commerce project.

## Jira Stories

- SNEAK-13 – Add Sneaker to Shopping Cart
- SNEAK-14 – Remove Sneaker from Shopping Cart

## Functionality

- Add sneakers to shopping cart
- Display selected products in cart
- Increase and decrease product quantity
- Automatically calculate cart total
- Remove products from shopping cart

## How to Run

1. Download and extract the project ZIP file.
2. Open `index.html` in a web browser.
3. Select a sneaker and click **Add to Cart**.
4. Click **Cart** to open the shopping cart page.
5. Change the quantity or click **Remove** to remove the product.
